# Компоненты

## Общие компоненты (`components/common/`)

### Обёртки данных

- **LoadingWrapper** — отображает индикатор загрузки или ошибку. Использовать `isLoading` вместо `!data` для предотвращения flash при обновлении.
- **ErrorWrapper** — обёртка для ошибок API
- **EmptyListWrapper** — сообщение при пустом списке
- **ErrorAlert** — MUI Alert для ошибок
- **ProgressContainer** — контейнер с индикатором прогресса

### Формы и ввод

- **CustomComboBox** — MUI Autocomplete с типизацией
- **CustomDialog** — MUI Dialog с стандартизированными действиями
- **CustomPassword** — поле ввода пароля с toggle видимости
- **CustomSwitch** — MUI Switch с меткой
- **MultiSelect** — множественный выбор из списка
- **SwitchWithOptionalLabel** — переключатель с опциональной подписью

### Кнопки и действия

- **ProgressButton** — кнопка с индикатором загрузки при async-операции
- **DeleteButton** — кнопка удаления с подтверждением
- **MenuButton** — кнопка с выпадающим меню
- **UploadButton** — кнопка загрузки файлов

### Прочее

- **Link** — React Router ссылка
- **PageLoadingIndicator** — полноэкранный индикатор загрузки
- **CustomAccordion** — MUI Accordion с кастомными стилями

## App Layout (`app/`)

### AppBar

- `AppBar.tsx` — десктопная навигация
- `MobileAppBar.tsx` — мобильная адаптивная версия
- `Search.tsx` — поисковая строка
- `mini-player/` — вторая, плотная строка тулбара: название играющей книги (ссылка на её
  страницу), пауза/воспроизведение и закрытие плеера. Видна, пока плеер занят и открыта не
  страница этой книги (`useMiniPlayerVisible`); распорка под fixed-баром повторяет условие,
  иначе содержимое уедет под бар. Кнопка воспроизведения показывает ошибку плеера цветом и
  тултипом: баннер `PlayerError` живёт на странице книги, а сбой теперь случается и вне её

### PlayerHost

`app/PlayerHost.tsx` — компонент без разметки, держит Media Session и wake lock всё время
работы приложения: воспроизведение переживает страницу книги, см. [player.md](player.md)

### Account Menu

- Выпадающее меню пользователя: профиль, смена пароля, привязанные аккаунты, ключи безопасности, кешированные главы, настройки, выход
- `cached-chapters/` — диалог управления кешем аудио: книги с закешированными главами (название, автор, число глав, занятое место), удаление кеша по книге и целиком. Книга определяется по URL главы (`useCachedBooks`), для отсутствующей в каталоге книги показывается её id. Пункт меню скрыт, если браузер не поддерживает офлайн-кеш (`mediaCacheSupported`); при непрочитанном состоянии кеша диалог сообщает об этом, а не показывает пустой список

- `linked-accounts/` — диалог привязки Telegram-аккаунта. Отказ виджета молчалив сам по себе, поэтому
  привязка идёт через `useTelegramLink`: он показывает тост и переводит причину по коду из тела ответа.
  Тем же хуком пользуется страница неактивного аккаунта, где привязка — способ активироваться

### Speed Dial (FAB)

- Плавающая кнопка с быстрыми действиями: добавить книгу, автора, чтеца, серию, пользователя (admin)

### Footer

- Copyright, ссылки, версия приложения

## Паттерны

### Диалоги как отдельные компоненты

Диалоги выносятся в отдельные файлы. Родительский компонент управляет состоянием открытия:

```tsx
const [open, setOpen] = useState(false);
<AddBookDialog open={open} onClose={() => setOpen(false)} />
```

### Организация компонентов

- Один компонент на файл
- Страницы — в `pages/`, с поддиректориями для сложных страниц
- Максимальный размер компонента ~250 строк, далее выносить в подкомпоненты
