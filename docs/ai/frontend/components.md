# Компоненты

## Общие компоненты (`components/common/`)

### Обёртки данных

- **LoadingWrapper** — отображает индикатор загрузки или ошибку. Использовать `isLoading` вместо `!data` для предотвращения flash при обновлении.
- **ErrorWrapper** — обёртка для ошибок API
- **EmptyListWrapper** — сообщение при пустом списке
- **ErrorAlert** — MUI Alert для ошибок
- **ProgressContainer** — контейнер с индикатором прогресса

### Формы и ввод

- **CustomComboBox** — MUI Autocomplete с типизацией
- **CustomDialog** — MUI Dialog с стандартизированными действиями
- **CustomPassword** — поле ввода пароля с toggle видимости
- **CustomSwitch** — MUI Switch с меткой
- **MultiSelect** — множественный выбор из списка
- **SwitchWithOptionalLabel** — переключатель с опциональной подписью

### Кнопки и действия

- **ProgressButton** — кнопка с индикатором загрузки при async-операции
- **DeleteButton** — кнопка удаления с подтверждением
- **MenuButton** — кнопка с выпадающим меню
- **UploadButton** — кнопка загрузки файлов

### Прочее

- **Link** — React Router ссылка
- **PageLoadingIndicator** — полноэкранный индикатор загрузки
- **CustomAccordion** — MUI Accordion с кастомными стилями

## App Layout (`app/`)

### AppBar

- `AppBar.tsx` — десктопная навигация
- `MobileAppBar.tsx` — мобильная адаптивная версия
- `Search.tsx` — поисковая строка

### Account Menu

- Выпадающее меню пользователя: профиль, смена пароля, привязанные аккаунты, ключи безопасности, настройки, выход

### Speed Dial (FAB)

- Плавающая кнопка с быстрыми действиями: добавить книгу, автора, чтеца, серию, пользователя (admin)

### Footer

- Copyright, ссылки, версия приложения

## Паттерны

### Диалоги как отдельные компоненты

Диалоги выносятся в отдельные файлы. Родительский компонент управляет состоянием открытия:

```tsx
const [open, setOpen] = useState(false);
<AddBookDialog open={open} onClose={() => setOpen(false)} />
```

### Организация компонентов

- Один компонент на файл
- Страницы — в `pages/`, с поддиректориями для сложных страниц
- Максимальный размер компонента ~250 строк, далее выносить в подкомпоненты
